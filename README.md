# PM2.5 Analysis - Saharanpur (Oct-Nov 2025)

## About
Hourly PM2.5 analysis near Saharanpur, India, using Python in Google Colab.

## Data
CAMS model data via the Open-Meteo API (model-based, 1,464 hourly values).
CPCB station files for Shamli were empty for these months, so model data was used.

## Results
- Mean PM2.5: 62.2 ug/m3 (Oct), 80.8 ug/m3 (Nov)
- 42 of 61 days (69%) above India's 24-hour standard (60 ug/m3)
- Worst day: 22 Nov 2025 (140.4 ug/m3)
- Peak at 23:00 (95.4), lowest at 15:00 (42.4)

## Limitations
Model-based data, only two months.

## Files
Untitled0.ipynb contains the analysis code.
